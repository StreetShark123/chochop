Cómo se usa

Arrastra sobre la onda para crear un corte (Alt para crearlo encima de otro). Doble clic crea uno del largo fijo. Arrastra el centro de un corte para moverlo y sus bordes para ajustarlo. Con un corte seleccionado, «Trocear» trabaja solo dentro de él.
